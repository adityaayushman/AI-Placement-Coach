### DKT vs BKT

Data: **SYNTHETIC** multi-skill sequences from `dkt.simulate_sequences` (10 skills,
1600 training and 400 held-out learners, 40 answers each).
DKT hyperparameters were chosen on a separate validation split.

| model | held_out_auc |
|---|---|
| DKT (LSTM, hidden 100) | 0.7056 |
| BKT, per-skill parameters fitted | 0.7224 |
| BKT, default parameters | 0.6902 |

On this data DKT does **not** beat fitted BKT. The generator is a
BKT-style process with one prerequisite link per skill, which suits BKT; DKT's advantage in the
literature comes from larger, messier real datasets. Served mastery therefore stays BKT by
default (`USE_DKT=false`).
